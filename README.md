# Kebede Taye Desta — Homepage

Personal academic homepage built with [Jekyll](https://jekyllrb.com) and the
[codinfox-lanyon](https://github.com/codinfox/codinfox-lanyon) theme.

Live site: https://ktdesta.github.io/

## Pages

| Page | File |
|---|---|
| About (home) | `index.md` |
| Members | `members.md` |
| Research | `research.md` |
| Publications | `publications.md` |
| Courses | `courses.md` |

Site title, sidebar text, contact links and navigation are set in `_config.yml`.
Theme colors are in `_scss/_config.scss`.

## Run locally

```sh
bundle install
bundle exec jekyll serve
```

Then open http://localhost:4000/
